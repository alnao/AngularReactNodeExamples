# React Corso Redux Client

Primo esempio del corso Redux, creato con Create React App: pagina con Materialize CSS, bottoni stilizzati con styled-components e un contatore scritto come class component. Redux non è ancora usato in questo passo.

| Scheda | |
|---|---|
| **Stack** | React 17, Create React App 5, Materialize CSS, styled-components |
| **Node** | 18 (vedi [`.nvmrc`](./.nvmrc), poi `nvm use`) |
| **Avvio** | `npm install && npm start` → http://localhost:3000 |
| **Backend** | Nessuno |
| **Stato** | In revisione |
| **Ultima verifica** | Non verificato di recente (progetto in revisione) |
