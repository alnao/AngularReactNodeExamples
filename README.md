## Prerequisiti

### 🔧 Software richiesto

Questi esempi necessitano *quasi* tutti di questi software:

| Software | Versione minima | Comando di verifica | Link download |
|----------|----------------|---------------------|---------------|
| **Node.js** | dipende dal progetto, vedi *Tecnologie* nella tabella e file `.nvmrc` | `node --version` | [nodejs.org](https://nodejs.org/) |
| **nvm** | qualsiasi | `nvm --version` | [github.com/nvm-sh/nvm](https://github.com/nvm-sh/nvm) |
| **npm** | quello incluso con Node.js | `npm --version` | Incluso con Node.js |
| **Angular CLI** | 16.x+ | `ng version` | `npm install -g @angular/cli` |
| **Ionic CLI** | 7.x+ | `ionic --version` | `npm install -g @ionic/cli` |

### 🟢 Versione di Node.js

Ogni progetto ha un file `.nvmrc` con la versione **major** di Node.js consigliata, riportata anche tra le *Tecnologie* di ogni progetto nella tabella e nella *Scheda* in cima a ogni README. La versione è ricavata dai requisiti (`engines`) del framework usato nel lockfile; per i progetti più vecchi (Angular 8-12, Create React App 3-4) serve una versione di Node vecchia, perché con Node 17 o superiori webpack 4 non parte (errore OpenSSL).

### 🚀 Quick Start

Per iniziare rapidamente con uno dei progetti:

```bash
# 1. Clona il repository
git clone https://github.com/alnao/AngularReactNodeExamples.git
cd AngularReactNodeExamples

# 2. Scegli un progetto e naviga nella cartella
cd [Nome-del-Progetto]

# 3. Usa la versione di Node indicata nel file .nvmrc del progetto
nvm install   # solo la prima volta
nvm use

# 4. Installa le dipendenze
npm install

# 5. Avvia il progetto
npm start
# oppure per progetti Angular:
ng serve
# oppure per progetti Node:
node server.js
```
